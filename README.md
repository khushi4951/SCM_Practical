README for Weather Website
Overview
AV Weather is a simple, responsive website that provides real-time weather updates and forecasts for any location. Users can check temperature, humidity, wind speed, and more in an intuitive interface.

Features
Live Weather Data: Get real-time weather updates.
5-Day Forecast: Plan ahead with accurate predictions.
Search by Location: Find weather details for any city.
Celsius/Fahrenheit Toggle: Switch temperature units easily.
Dynamic UI: Backgrounds and icons change based on weather.
Technologies Used
HTML, CSS, JavaScript
Weather API for real-time data
How to Use
Enter a city in the search bar and press "Search."
View detailed weather conditions.
Toggle temperature units if needed.
